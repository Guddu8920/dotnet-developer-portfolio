# .NET Developer Portfolio

Static portfolio made with HTML, CSS and JavaScript.

## Before publishing
1. Replace `your.email@example.com` with your email.
2. Replace GitHub and LinkedIn URLs.
3. Add your real education details.
4. Put your resume PDF in this folder and name it `resume.pdf`.
5. Add your actual project GitHub URL and live demo URL.

## Run locally
Open `index.html` in your browser.

## GitHub Pages
Create a GitHub repository, upload `index.html`, `style.css`, `script.js`, and `resume.pdf`, then:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
Your site will appear at:
https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
